# راهنمای فارسی فرمان‌های reel-motion-edit

## درخواست با زبان طبیعی

این عبارت‌ها را به دستیار بگو؛ دستور PowerShell نیستند. فایل یا مسیر ویدیو را هم بده. نام سبک به شناسهٔ واقعی `style` در `assets/styles.json` نگاشت می‌شود؛ انتخاب صریح کاربر را با سبک حدسی جایگزین نکن.

```text
این ویدیو را به سبک نیاس ادیت بزن: «مسیر فایل»
این ویدیو را هوشمند ادیت بزن؛ گفتار را تحلیل کن و سبک مناسب پیشنهاد بده.
به سبک نیاس ادیت بزن؛ برای هر مفهوم المان مرتبط و برای شاهدها اسکرین‌شات واقعی بیاور.
به سبک نیاس ادیت بزن؛ لوگوها روی نام برند و پشت سر ظاهر شوند.
به سبک نیاس با تم بیزنسی ادیت بزن؛ موسیقی corporate با گین -20 dB، ووش و زوم‌اوت ساده با فلش کوتاه.
ثانیهٔ ۲۷ تا پایان این جمله را تمام‌صفحه موشن‌گرافیک کن؛ زیرنویس کمی پایین‌تر بیاید.
در ۱:۳۷ از اسکرین‌شات‌های review و در بخش پشتیبانی از support استفاده کن.
آدرس بخش ۱:۵۰ را به cod24.ir اصلاح کن؛ نسخهٔ کامل و پیش‌نمایش همان بخش را بده.
```

محدوده‌ها، نام فایل‌ها و آدرس‌ها در مثال‌های بالا متعلق به یک تدوین‌اند؛ برای درخواست تازه آن‌ها را از ورودی همان کار بگیر. «به سبک نیاس» دستور کامل [طراحی مفهومی نیاس](nias.md) را فعال می‌کند، نه فقط پریست رنگ. «ریلز آماده انتشار» بستهٔ کامل می‌خواهد و «فقط ادیت» خروجی ویدیو.

## فرمان‌های فنی

فرمان‌ها برای PowerShell و از ریشه پروژه‌اند. برای یک کار پوشه‌ای جدا مثل work/reel بساز. Node.js، Python، Chrome یا Edge و ffmpeg/ffprobe باید در دسترس باشند. هر اسکریپت دارای argparse با --help همه گزینه‌های فعال نسخه را نشان می‌دهد.

## مسیر اصلی، به ترتیب

```powershell
python scripts/setup.py --skip-model
python scripts/analyze.py "work/reel/source.mp4" work/reel --lang fa
python scripts/captions.py work/reel --style highlight --fix "وی پی ان=VPN"
node scripts/render.js work/reel/plan.json check --strict
node scripts/render.js work/reel/plan.json preview 0.6 2.6 4
node scripts/render.js work/reel/plan.json full
python scripts/compose.py work/reel/plan.json --out work/reel/final.mp4
node scripts/render.js work/reel/plan.json cover 0.8
python scripts/verify.py work/reel/final.mp4 --instagram --cover work/reel/build/cover.jpg --post work/reel/post.txt
```

setup فقط بار اول؛ با حذف --skip-model مدل هم آماده می‌شود. بعد از analyze بیت‌شیت و plan.json را بنویس؛ نمونه نیاس در [examples](../examples/plan.nias.json) است. در پلن، مسیرها نسبت به پوشه پلن‌اند. برای زیرنویس، captions.file را captions.json بگذار و متن خروجی را تصحیح کن. برای بسته کامل delivery را instagram بگذار و cover.lines و post.txt را دستی بنویس. زمان‌های پیش‌نمایش و کاور باید از خود ویدیو باشند. اگر check خطا داد، قبل از full آن را رفع کن. verify مشخصات فایل‌ها را می‌سنجد، نه کیفیت تدوین یا خوانایی.

## همه فرمان‌های موتور Node

| فرمان پس از نام plan.json | کاربرد |
|---|---|
| check یا check --strict | زمان‌بندی و عیب‌یابی؛ strict یا delivery=instagram برای خطاهای مانع تحویل کد ناموفق می‌دهد. |
| preview T1 T2 ... | استیل‌های ترکیب‌شده و شیت پیش‌نمایش در build. |
| full | ساخت overlay.mov و فایل‌های میانی کامپوز. |
| styleboard T | مقایسه پریست‌ها روی فریم T. |
| styleboard T plan STYLE1 STYLE2 | مقایسه صحنه طراحی‌شده با سبک‌های انتخابی. |
| cover T | ساخت build/cover.jpg با تیتر مستقل. |

## موتور استودیو (GSAP + Three.js) و بررسی دستی

برای اجرای استودیو یا رندر مستقیم پروژه با موتور چندلایبرری:

```powershell
node studio/gsap_renderer.js "studio/projects/<id>" check
node studio/gsap_renderer.js "studio/projects/<id>" preview
node studio/gsap_renderer.js "studio/projects/<id>" full
ffprobe -v error -show_format -show_streams "studio/projects/<id>/final.mp4"
```

در آخر، [بازبینی انتشار](release.md) را روی فایل نهایی انجام بده.

برای قلاب نیاس، در پلن از `{"type":"title","anim":"focus","t":0.04,"d":2.4,"lines":["برای فروشگاهت","*کدام سرویس؟*"],"focusAt":0.42,"jitter":false}` استفاده کن. برای تأکید گزینشی زیرنویس، `focusOnly: true` را در تنظیمات `captions` و `key: true` را فقط برای کلمه‌های منتخب در فایل زیرنویس بگذار. نمونه حرکت نرم در آرایه `camera` به‌شکل `{"t":0.32,"d":1.72,"type":"zoom","scale":1.13,"cx":530,"cy":845}` است. حرکت دوربین در فایل ترکیب‌شده با `compose.py` دیده می‌شود.

در نیاس، `python scripts/captions.py WORKDIR --style nias --keywords "رهگیری,لیبل,بارکد" --alt "لیبل"` واژه‌های منتخب را علامت می‌زند. برای تنظیم زمینهٔ مشکی شفاف از `"shade":{"height":0.62,"opacity":0.88}` در `captions` استفاده کن. برای ترنزیشن سفارشی، `"sfx":[[0.025,"whoosh_short",-5]]` را روی رویداد ترنزیشن بگذار. برای مورف، `data-morph="مسیر مقصد"` را روی مسیر SVG با همان نوع و ترتیب دستورهای `d` اضافه کن. `data-morph-at` و `data-morph-dur` زمان نسبی و مدت حرکت را بر حسب ثانیه تنظیم می‌کنند.

برای استفاده از تیتر به‌جای زیرنویس جملهٔ اول، `lines` را از گفتار و `lineAt` را از زمان نسبی ورود هر سطر پر کن. زیرنویس عادی را از زمان جملهٔ دوم نگه دار. اگر تیتر در نیمهٔ پایین است، `"layer":"hud","maxWidth":760` آن را روی گرادینت و دور از دکمه‌های اینستاگرام قرار می‌دهد. برای موسیقی زمینه ابتدا `python scripts/music.py WORKDIR/music.wav --mood calm --dur SECONDS` را اجرا کن، سپس مسیر فایل و تنظیمات `{"file":"مسیر فایل","db":-14,"duck":true}` را به `music` در پلن بده.
